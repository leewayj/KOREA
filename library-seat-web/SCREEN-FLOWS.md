# 화면 흐름

375 × 812 기준, 백엔드 없이 브라우저 세션에 임시 예약을 저장합니다.

- 예약이 있으면 HOME의 버튼/제목과 열람실 카드가 좌석 변경으로 표시됩니다. 열람실 선택 → 06 변경할 좌석 선택 → 팝업 확인 → 내 예약 정보로 이동합니다. 다른 열람실로 바꿔도 시작·종료 시간은 유지합니다.
- 예약이 없으면 HOME의 좌석 예약 → 열람실 선택 → 04 배치도로 이동합니다.
- 04 배치도 → 05 좌석 선택 팝업 → 예약하기 → 08 예약 정보
- 08 좌석 변경 → 06 변경할 좌석 선택 → 07 팝업에서 확인 → 변경된 내 예약 정보 (08/11)
- 08/11 예약 연장 → 12/13 (종료 시간 +2시간, 시작 시간과 좌석 유지)
- 종료 10분 이내 → 14 빨간 타이머/종료 임박 표시
- 시간 만료 → 15 예약 종료 → 새로 예약하기 또는 HOME
- 07 팝업의 확인에서 좌석 변경을 반영합니다. 취소는 기존 좌석을 유지합니다. 중간 09/10 화면은 제거했습니다.

## 개발 서버에서 시간 상태 확인

다음 미리보기는 정상 세션 예약과 분리되며 프로덕션 빌드에서는 비활성화됩니다.

- `http://localhost:5173/?preview=ending#reservation`: 종료 10분 전
- `http://localhost:5173/?preview=expired#reservation`: 예약 종료
- `http://localhost:5173/?preview=expiring#reservation`: 5초 후 자동 종료

미리보기에서 벗어나려면 `http://localhost:5173/#reservation`으로 이동합니다.

검증: `npm test`, `npm run lint`, `npm run build`
