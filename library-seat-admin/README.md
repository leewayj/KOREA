# 도서관 좌석 관리자

피그마의 관리자 6개 화면을 구현한 독립 React + Vite 앱입니다. 사용자 앱과 별도 설치·실행·빌드하며, 서버나 실제 센서에는 연결하지 않습니다.

## 실행

```sh
cd library-seat-admin
npm ci
npm run dev
```

http://127.0.0.1:5174 에서 확인합니다. Node.js 22.12 이상을 사용하세요.

```sh
npm test
npm run build
npm run preview -- --port 4174
```

## 화면과 시연

- `#home`: 열람실별 혼잡도와 예약 현황. 홈 카드에서 각 열람실로 이동합니다.
- `#rooms/reading-2`: 좌석 목록 및 전체·예약 중·확인 필요 필터.
- `#create/reading-2/67`: 가상 예약 등록. 관리 좌석은 열람실별 66~71번입니다.
- `#seat/reading-2/66`: 예약, 착석, 센서와 장치 상태, 예약 삭제 확인창.
- `#edit/reading-2/66`: 남은 시간 빠른 조정 및 시작·종료일시 수정, 다음 예약 확인.
- `#settings`: 기본 예약 시간 및 최대 연장 횟수.

첫 실행 시 66번은 45분, 68번은 75분 남은 예약으로 생성합니다. 66번에는 75분 후 시작하는 다음 예약이 있어 중복 검증을 확인할 수 있습니다. 70번은 예약 만료 후 착석, 71번은 상태 미확인입니다. 시간은 실제로 흐르며 모든 날짜 입력은 한국 표준시입니다.

브라우저 localStorage의 `library-seat-admin-demo-v1` 키에 변경 사항을 저장합니다. 사용자 앱 데이터와 공유되지 않습니다. 초기 시연 상태로 복원하려면 해당 키를 삭제하고 새로고침하세요. 서버 인증이 없는 로컬 시연용 앱입니다.

홈의 반복된 피그마 예시 이름 대신 기존 사용자 앱의 네 열람실 이름을 적용했습니다. 데스크톱에서도 390px 모바일 디자인을 중앙에 유지하며 작은 화면에는 너비를 맞춥니다. 피그마 프레임 밖으로 넘친 수정 화면 하단은 스크롤로 접근할 수 있습니다.

## 추후 백엔드 연결

`src/data/store.js`에 시연 데이터 생성·조회·검증을 모았습니다. API 연결 시 앱의 loadData/commit 경계를 비동기 API로 교체하고 조회 로딩·오류 상태를 추가하세요. 서버에서도 예약 시간 중복 검증, 관리자 인증/권한, 운영 설정 적용이 필요합니다. 연장 횟수는 새 예약에 스냅샷으로 보관하며 사용자 연장 API는 이 값을 검사해야 합니다. 실제 센서/LED 프로토콜은 미정으로 현재 고정 시연 상태입니다.

Button은 사용자 앱의 Figma SDS Code Connect 컴포넌트를 재사용했으며, 연결된 InputField/Input은 기존 코드에 없어 접근 가능한 label/input으로 구현했습니다. Figma 아이콘과 Noto Sans KR 폰트는 public/assets에 포함되어 있습니다.
