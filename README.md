# KOREA

## 프로젝트 소개

이 저장소는 팀 프로젝트를 위한 공간입니다.

## 개발 방식

- 각 팀원은 별도의 Branch에서 작업합니다.
- Pull Request를 통해 변경 사항을 공유합니다.

## 커밋 메시지는 한국어로 작성

- feat - 새로운 기능 추가
  ex. feat: 데이터 저장 기능 추가
- fix - 버그 수정
  ex. fix: 로그인 인증 오류 수정
- refactor - 코드 구조 개선 (동작 유지)
  ex. refactor: 로그인 인증 로직 분리
- docs - 문서 수정
  ex. docs: 로그인 기능 사용법 추가
- chore - 기타 유지보수 작업
  ex. chore: 개발 환경 설정 업데이트
- style - 코드 포맷 수정
- test - 테스트 추가 및 수정
